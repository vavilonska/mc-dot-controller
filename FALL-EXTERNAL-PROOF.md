# Native fall-rescue external-controller consumption

Declared base: integrated recovery source with accepted native fall R3 and navigation r2.

The fall controller now queries the pinned, read-only external-controller adapter at arm/renew, before episode ownership/preemption, during tracking, and at the final bucket effect and packet boundaries. Every effect query precedes the final pure original-episode, arbiter, world/player and deadline checks. Fresh proof never clears quarantine or authorizes a replacement owner.

The original standalone Baritone distribution stays unsupported. Only the adapter's exact supported idle API distribution, or proven absence, can pass. Busy and unknown both refuse. Off-game-thread capability discovery reports idle as unproven; coherent game-thread state observations provide current availability.

This delta does not add automatic Baritone cancellation, route handoff, concurrent public movement protection, or a rescue guarantee. Live performance and survival outcomes remain unverified.
