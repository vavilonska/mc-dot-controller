# Bounded composable cardinal segment

`movement-local-segment-observed-v1` is a separate native `follow_path` profile for exactly one cardinal flat, up-one or down-one edge. It does not change the legacy flat, collection, pedestal-descent, PathSteering or MovementBudget contracts. A bounded public route can request several separately witnessed segments under its original shared owner and cumulative budgets.

## Native contract

- Private Overworld survival; exact ordinary LocalPlayer, body, gravity, movement and jump attributes; no sprint, auto-jump, effects, fluids, hazards, flight, manual input or open menu. Complete existing entity readers and immutable original ownership/context/freshness fences apply. MovementBudget must stay unarmed.
- Source feet X/Z within .10 per axis of cell center; exact integer source and target Y; both feet heights in [-63,316]. One destination center, cardinal distance one, height difference -1/0/+1. Public jump/sprint/sneak controls are refused.
- Each action is bounded to 8 seconds and fewer than160 native Pre ticks; airborne phase at most20 ticks. Horizontal velocity≤.30, sampled horizontal displacement per action tick≤.35 and total≤2; absolute sampled vertical displacement per action tick≤.5, vertical velocity magnitude≤.5, upward apex≤1.26, fall distance≤1.01.
- Body center stays in the straight cardinal corridor: cross-axis≤.10, longitudinal range source−.10 to destination+.10. Actual body cannot penetrate either the ascending riser below its top or the departing descending source pedestal. Partial overlap with the upper support is permitted for actual vanilla landing collision.
- The150-cell flat or180-cell elevation prism keeps a two-cell context halo. Required source/target columns have explicit support/clear roles. Flat support is feetY−1 and air occupies feetY..feetY+1. Upward source air extends through sourceY+3; target support is sourceY, and target air sourceY+1..sourceY+3. Downward source air is sourceY..sourceY+2; target support sourceY−2 and air sourceY−1..sourceY+2.
- Required supports remain the12 ordinary full-cube floor types. Every context cell is either literal dry air, an ordinary floor cube, or exact vanilla BarrelBlock/FurnaceBlock, or oak/birch LeavesBlock, with full-cube collision and ordinary .6 friction. Context foliage and workstations are never promoted to support/clear cells. Every observed state is immutable for the segment; a furnace lit change or leaf distance/decay change may conservatively cancel. Waterlogged leaves refuse. No block entity interaction occurs.

## Input and composition

The controller aligns while neutral. Before an upward pulse it physically centers within .02 of the source and waits for vanilla to reduce horizontal velocity naturally to exactly zero. One neutral input tick precedes one vertical jump pulse. The pulse is consumed at actual input injection, never by a planning decision. No horizontal input is injected below the riser top; after actual feet clear it, ordinary full-strength non-sprint air input crosses. Ground steering tapers near the goal and stops around .04, rather than the legacy .23 radius. Success requires exact destination Y, grounded/fall-distance zero, center radius≤.08, horizontal speed≤.003, ordinary vertical residual [-.09,0], two distinct native action ticks and neutral input release. This endpoint fits the unchanged .10 next-source envelope.

A required `Entity.move` HEAD hook retains the original one-tick owner token across a NeoForge jump callback. It rechecks terrain, entities, attributes and exact owner/context immediately before SELF motion. The first upward move must preserve the original pose and zero XZ with exact vanilla .42F impulse. Recursive/duplicate moves, other mover types, stale/unconsumed tokens and jump-hook mutations fail closed. Gate failure marks canonical `unknown_outcome` on the original retained Entry even if that owner was replaced; it never releases a replacement owner's action. Cancellation prevents the imminent guarded move but does not rewrite velocity or certify stopped gravity. The next tick clears the spent gate so unrelated later vanilla motion is not indefinitely blocked. Later arbitrary collision-hook effects remain uncertified.

Profile negotiation is unavailable until the required motion hook has actually run. Full Mixin/client lifecycle and ordinary-world gameplay must be tested on the final artifact before release. A component collision/recurrence test does not establish that lifecycle.

## Reproducible source-only suite

Run `python -B client-mod/validation/local-segment/run_all.py --repo . --output /new/external/output --java /jdk21/bin/java --javac /jdk21/bin/javac --gson /deps/gson.jar --classpath-file /deps/compile-classpath.txt` from the checkout. It uses existing trusted dependencies and fresh output directories only, never installs/downloads/launches a game or retries an existing output. Python3 and Node.js are required.

The suite compiles current production policy/controller/motion-gate/entity/registry/codec sources against explicitly synthetic reader doubles, exercises exact extracted owner queries/failure marking, then freshly compiles the full production Java tree and emits native serializer wire for flat/up/down and an actual production gate refusal under those doubles. Python consumes these original bytes, and actual Node MCP/Python Owner/Watchdog/Resident frontdoor tests use a synthetic native endpoint. Source-relation tests preserve existing accepted movement source hashes.

`ScopedLocalSegmentLoaderTest` additionally provides real FML/Mixin `Entity.move` injection tests through the existing `bridge.realLoaderTests` bootstrap. Its receiver is allocation-only with collision disabled, so even that test is not ordinary-world physics. Record whether this stage was actually run; do not infer a pass from compilation.

Neither prescribed controller samples, component engine method tests, serializer fixtures nor source relation tests establish a live world, complete ClientActions lifecycle, final artifact deployment, saved state or general navigation acceptance. Unknown outcomes are never retried or resumed.
