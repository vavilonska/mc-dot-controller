# V6 offline validation

Run `python run-offline.py --out <new-results-directory>` from any directory. The runner resolves the copied source and pinned local Java 21/AT classpath. It compiles all production Java, compiles actual tests, and starts ordinary Java test mains only. It does **not** bootstrap Minecraft, create a world/player/entity, invoke GLFW, install artifacts, or issue HTTP.

- `RecoverySurvivalV6Checks`: actual production parser, closed requests/digests, existing journal/TTL/stop/UNKNOWN/release paths, production finite `UseBound` and selection/reach predicates. Synthetic callback chronology explicitly models normal return, stop or expiry during a call, one start, normal 32-tick finish/boundary, and replacement ownership. These are not live item/Blaze effects.
- `RecoverySurvivalLegacyOracle`: independently compiled and run with both frozen C5 and C6 production classes. Actual frozen 338-entry journal roundtrips byte-identically; all 338 actual production receipt JSON lines and payload digests match. Existing IDs are read-only exact duplicates in explicit V6 mode; altered payloads and new old-profile IDs are rejected.
- `RecoverySurvivalPinnedChecks`: exact pinned native bytecode and compiled C6 method chronology. Confirms LocalPlayer's local use flag, server completion event before item consumption, client finish then stop in one callback, current combined ray's strict distance bounds, one top-level attack/use, post-call live check, default-repeat latch lifetime, original cleanup outside the ledger monitor, and the required Mixin installation/read seam. It does not claim a live Mixin loader run.
- `RecoverySurvivalV6ObservationWire`: explicitly synthetic food/Blaze facts and previously exported cold terrain shape models through production Geometry and JSON encoding. No live geometry or target capture is represented. Includes null/no-world/incomplete/use-in-progress and accepted short / rejected oversized 512-box cases.

Old short-input, interaction V1/V2/V3, respawn UI, navigation V4 and maintenance V5 checks also run against the candidate classes. Old source/profile semantics and limits remain protected separately; V6's only TTL extension is the new consume kind (4 seconds). Ticket freshness remains 2 seconds / 40 ticks, independent of the absolute submit deadline. A normal returned use FAIL is an attempted call, not proof no packet was sent. No outcome fixture asserts server-side damage or causal consumption.

Final packaging must use the frozen result/source/class manifest, retain all predecessor classes, and change only classes owned by the selected changed/new source files plus the required Mixin JSON. Actual input/world/loader qualification remains an independent authorized TEST, never a claim made by these offline tests.
