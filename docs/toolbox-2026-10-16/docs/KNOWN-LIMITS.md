# 已知限制与未完成项

本包可以诚实交付为限定可用候选；以下边界仍是接口合同，不能把小场景实测扩大成“全部能力、所有场景成功”。

## 必须保持的安全边界

- 只用于授权私有单人；保留原世界。不开多人、不自动复活/切服，不擅自恢复暂停任务。
- unknown 永远不能当作零效果。使用原 `request_id` 查状态/对账；换 ID、换 journal、重启进程或重发 POST 都不是恢复方案。
- `defend_once` 是同一 owner 下的一次有界防御动作，可包含预算内多次攻击；不是“一次攻击”的同义词。普通任务被中断后不恢复。默认反应仍是 `stop`。
- 观察、效果和释放是不同事实。`isBlocking` 表示客户端盾牌格挡状态，不能替代实际挡伤统计；目标血量下降也不单独证明所有服务端最终状态。
- 所有公开结果仍是 client-observed；`server_confirmed:false`。保存检查只证明检查过的字段。
- 若最新绑定、几何/威胁覆盖、冷却/射线/目标条件不满足，允许拒绝；不得放宽安全准入以凑成功率。

## 本版本未完成的实机覆盖

1. 防御：实际盾挡伤害及其统计增长；健康采样间隙后完整恢复；真实低血/风险剩余撤离；真实暂停、`/tick freeze` 和恢复生命周期。这些不能用离线样例或单次无位移结果替代。
2. 在当前 59523ef… JAR 上重新跑完整 T42 十一任务工坊链。T42 的成功保留为旧 64aaa… JAR 的限定实机证据，不自动迁移到新构建。
3. 多目标/混合敌人、一般遭遇生存、复杂地形、未知/未加载区块路线、长距离连续操作及长期可靠性。
4. 原生 Windows 完整 owner 链，跨主机/跨 namespace 传输，不同 NeoForge 小版本及不同机器性能的实机兼容性。
5. 未接入公开后端的目录能力、完整建筑施工、任意配方/容器/物品/维度与资源目标全流程。catalog 中能看到条目不等于可执行。
6. 真实网络/进程故障注入、失联后的可靠清理及自动正常关闭的全场景覆盖；不得为了该覆盖重试历史 unknown。

## 必须保留的历史结果

- T43 原 unknown 保持，禁止重试/重分类。
- T44 typed stop-proof 路径实机有效，但完整防御功能试验失败，仍保留失败。
- T45 在防御前遇到已知 HTTP 409 / 零效果拒绝并 blocked；历史失败帧缺失，不能声称已还原根因或“修复了那一帧”。当前诊断改动增加有界拒因，不降低门槛。
- T42 的自动收尾 HOLD 与后续人工正常关闭分开记录；严格保存 aggregate=false，不能称整个世界未变化。
- 更早 T22/T26/T28 unknown 及 T24/T32 等自动收尾 HOLD 以各自原记录为准；后来的成功不会覆盖它们。
