# T46：本包同版本的核心防御实机结果

本轮在独立普通单人测试副本中，使用本包 59523ef… JAR 与配套 1,034 文件 runtime。最终机器回执状态为 `CORE_DEFENSE_LIVE_PASS_SAVED_WITH_EXPLICIT_COVERAGE_LIMITS`，而 `all_requested_defense_goals_verified=false`。详细数字见 [T46 摘要](../evidence/T46-SUMMARY.json)。

## 已证明

- stop-only 在普通路线产生移动前抢占；随后同一 owner 执行 `defend_once`，`approach=false`、`shield=true`。公开 route 保持 `interrupted`，不会自动续走；这是安全的预期结果，不应把整个 route 标记为 succeeded。
- 原生派发 3 次攻击，客户端目标僵尸血量从 20 到 0，观察到 3 次下降；保存统计 `damage_dealt` 从 3738 到 3938（原始单位 +200），剑磨损 +3。不声称每击服务端确认或精确单击伤害归因。
- 客户端 `isBlocking` 共观察到 14 ticks；玩家血量保持 20，位移 0。
- 普通保存/退出完成。游戏原自动数值投影仍是 null；另有独立审查的当前游戏 console 明确 exit 0，原件未改写。Launcher、Resident、Watchdog、MCP 均 exit 0；13 个精确已知进程身份已退出，无待决 GUI 输入。没有用信号强杀替代正常收尾。
- 稳定保留并逐文件校验 33 文件、16,079,282 字节的关闭后存档副本。82 格测试小屋、无关背包和玩家位置保持；当前/备份玩家镜像一致，血量/食物均为 20。
